# 宠物模型图片目录

将你的宠物图片放到这里！支持以下状态：

## 文件命名规范

| 文件名 | 状态 | 说明 |
|--------|------|------|
| `idle.png` | 空闲 | 宠物日常待机状态 |
| `eating.png` | 进食 | 喂食时的状态 |
| `sleeping.png` | 睡眠 | 睡觉时的状态 |
| `playing.png` | 玩要 | 玩要时的状态 |
| `happy.png` | 开心 | 心情值高时的状态 |
| `sad.png` | 伤心 | 心情值低时的状态 |
| `sick.png` | 生病 | 健康值低或死亡时的状态 |

## 图片要求

- 格式：PNG（支持透明背景）
- 推荐尺寸：200x200 像素
- 透明背景效果最佳

## 使用说明

1. 将图片按上述命名放入此目录
2. 在应用中点击“重载素材”按钮
3. 程序会自动加载并替换占位图

如果没有提供图片，程序会自动使用内置的占位图形运行。

# Sounds Directory

## 如何让宠物唱歌

### 放入歌曲

将你的 MP3 文件改名为 `song.mp3`，放入此目录：

```
assets/sounds/song.mp3
```

然后右键宠物 -> 点击"🎵 唱歌"，宠物就会拿起麦克风唱 27.5 秒！

### 没有歌曲文件时

如果没有 `song.mp3`，宠物会使用蜂鸣声播放一段欢快旋律（不需要任何音频文件）。

### 支持的格式

- 格式：MP3
- 文件名：必须为 `song.mp3`
- 文件大小：建议 5MB 以内（约 30 秒）

### 注意

- 请确保你有合法使用该音频文件的权利
- 歌曲播放时宠物会左右摇摆、拿麦克风
- 再次点击"停止唱歌"可以提前停止

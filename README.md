# Electronic Pet (电子宠物)

一个桌面电子宠物应用。宠物以透明窗口形式悬浮在桌面上，可以拖拽移动、右键交互、双击显示状态面板。

## 功能特性

- **桌面悬浮**：透明无边框窗口，宠物直接悬浮在桌面上
- **鼠标拖拽**：按住宠物拖拽到桌面任意位置
- **右键菜单**：右键宠物弹出交互菜单（喂食、玩耍、睡觉、洗澡、抚摸）
- **双击面板**：双击宠物显示/隐藏浮动状态面板
- **悬停提示**：鼠标悬停时显示当前状态
- **单击抚摸**：单击宠物 = 抚摸互动
- **状态系统**：饱食、心情、精力、健康、清洁度
- **动画系统**：7种状态表情（空闲、进食、睡眠、玩耍、开心、伤心、生病）
- **时间系统**：状态随时间衰减，离线后状态继续变化
- **存档系统**：自动保存/加载宠物状态
- **自定义模型**：支持替换 `assets/sprites/` 中的图片素材

## 下载安装

### Windows

1. 下载 ZIP 压缩包并解压
2. 双击 `install-windows.cmd`
3. 桌面会创建"电子宠物"快捷方式，双击即可运行

**前提条件**：已安装 Python 3.8+（[python.org](https://www.python.org/downloads/) 下载，安装时勾选 "Add Python to PATH"）

### macOS

1. 下载 ZIP 压缩包并解压
2. 双击 `install-macos.command`
3. 桌面会创建"电子宠物"启动器

### 从源码运行

```bash
git clone https://github.com/KingBoy1988/electronic-pet.git
cd electronic-pet
pip install -r requirements.txt
python main.py
```

## 交互方式

| 操作 | 效果 |
|------|------|
| **单击宠物** | 抚摸（增加心情值） |
| **双击宠物** | 显示/隐藏状态面板 |
| **拖拽宠物** | 移动到桌面任意位置 |
| **右键宠物** | 弹出交互菜单 |
| **悬停宠物** | 显示当前状态文字 |

## 右键菜单

- 🍖 喂食 - 恢复饱食度
- 🎾 玩耍 - 提升心情（消耗精力）
- 💤 睡觉/醒来 - 恢复精力
- 🛁 洗澡 - 提升清洁度
- 🤚 抚摸 - 小幅提升心情
- 👁️ 显示/隐藏面板
- 💾 保存
- ❌ 退出

## 自定义宠物模型

将宠物图片放入 `assets/sprites/` 目录，按以下命名：

| 文件名 | 用途 |
|--------|------|
| `idle.png` | 空闲状态 |
| `eating.png` | 进食状态 |
| `sleeping.png` | 睡眠状态 |
| `playing.png` | 玩耍状态 |
| `happy.png` | 开心状态 |
| `sad.png` | 伤心状态 |
| `sick.png` | 生病状态 |

图片要求 PNG 格式（透明背景），推荐 256x256 像素。
